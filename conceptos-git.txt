Repositorio:Es un espacio para el almacenamiento de código fuente, dicho de otra manera, es un almacenamiento digital usado por los desarrolladores para rastrear, ejecutar y administrar código fuente. En el caso de un repositorio de GitHub esta plataforma incluye un conjunto de herramientas que permiten la gestión de proyectos. Algunas partes claves son: El historial de versiones, Archivo Readme, código fuente, carpetas e incidencias.
Commit: Es un comando para registrar como guardado un trabajo cuando se trabaja con un código, además permite saber que cambio se realizo y una vez creado el commit no se pueden deshacer los cambios. 
Push: Es un comando que se encarga de hacer visible los puntos de control guardados o commits, de esta forma se envía el código que hemos creado desde nuestra computadora hasta la nube, es importante hacer push porque sino lo hacemos los cambios realizados al trabajo no se verán reflejados en GitHub.
